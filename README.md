# School Frontend

Public school website built with Vite, React 19, Tailwind CSS 4, React Router, i18next (EN/AR), and shadcn/ui.

## Setup

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — start development server
- `npm run build` — production build
- `npm run preview` — preview production build
- `npm run lint` — run oxlint

## Stack

- React 19 + TypeScript + Vite 8
- Tailwind CSS 4 + shadcn (base-nova)
- react-router-dom, i18next (Arabic RTL / English LTR)
- axios, zustand, zod, react-hook-form, sonner, recharts

Copy `.env.example` to `.env` and set `VITE_API_BASE_URL` when connecting to a backend.
